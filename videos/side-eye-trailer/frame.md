# frame.md: African Household Drama

The trailer wears the game's own skin (`src/styles.css` in the game repo). Brand truth below; video scale is adapted per `hyperframes-creative/references/video-composition.md`.

## Palette (from the game's `:root`)

| Token | Hex | Role |
| --- | --- | --- |
| night | `#120c10` | canvas, every scene's base |
| ink | `#1d1420` | outlines, borders, text on paper |
| cream | `#fff7e6` | primary text on night, bubbles, choice cards |
| paper | `#f7e6c4` | narration captions, report card |
| amber | `#f2b53c` | the single accent: kickers, numbers, "African" in the wordmark |
| coral | `#e5583f` | heat: "Drama", warnings, the CTA button |
| terracotta | `#b8432c` | Mummy's name tag, warm glows |
| green | `#2f8a5b` | rare: approval / good outcomes |

## Type

- Display: **Fraunces** 600 (and 400 italic for narration), tracking -0.02em.
- Body / UI: **DM Sans** 700–800 for choices, bubbles and buttons.
- Data / kickers: **Space Mono** 700, uppercase, wide tracking.

## Language

- Speech hangs off people as cream bubbles with a 4px ink outline and a coloured name tag.
- Narration is a paper caption with an ink border, slightly rotated, italic Fraunces.
- Comic stickers (`assets/fx/*.webp`) burst beside faces on the punchline.
- Hard ink drop shadows (offset, no blur), never soft UI shadows.

## Don'ts

- No gradient text, no neon, no pure #000/#fff.
- No invented claims: only things the game actually contains.
