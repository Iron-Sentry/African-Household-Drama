# Audio credits

Every sound in `public/assets/audio/` is a trimmed, loudness-normalised copy of a recording from [Freesound](https://freesound.org). CC0 recordings need no credit but are listed anyway. CC BY recordings must stay credited here and in the in-game Settings → Sound credits. To swap a sound, replace its file and keep this table in sync; the cue → file map is in `src/audio/audio.ts`.
